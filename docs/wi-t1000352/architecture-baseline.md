# 架构基线：笑脸界面（测试任务一）

- 路线：`simple-frontend`（compact 精简路线）
- 需求基线：本文档引用并服从已批准的需求快照 `docs/wi-t1000352/requirements.md`（SHA-256 `d295da6ecba432aecf3c72fb238e689ea51afc5b1898fb6ed8b2ad8a91724bd8`），不重新定义产品语义，不新增或裁剪任何需求。

## 1. 应用形态

- 新建 React/Vite 单页应用（SPA），仅包含一个页面组件，根路径即笑脸页面。
- 无路由、无多页面、无网络请求；不引入任何自定义服务端、数据库、认证、后台任务或外部集成。
- 笑脸以 SVG 矢量图形绘制，内联在页面组件中渲染，随视口等比缩放并居中显示。

## 2. 页面与交互范围

单一页面在浏览器视口中央呈现一个完整笑脸，由三个视觉元素组成：

| 表情元素 | 技术承载 |
| --- | --- |
| 圆形脸部 | SVG `<circle>` 作为面部轮廓与底色 |
| 眼睛 | 左右对称的两个实心圆点（SVG `<circle>`） |
| 上扬的嘴角 | 一条向上弯曲的 SVG `<path>` 二次贝塞尔曲线 |

- 交互范围：无。需求未规定任何交互行为，页面不包含输入、按钮或动态逻辑，打开即呈现完整笑脸。
- 配色、尺寸与布局细节属需求未规定事项，实现采用单一默认方案（例如黄色面部 + 深色五官），不影响验收语义。

## 3. 浏览器状态与数据归属

- 本应用无业务数据、无持久化需求：不使用 `localStorage`，不读写任何浏览器存储，也不存在任何服务端权威数据。
- 页面为无状态纯渲染：刷新或重新打开页面后呈现同一笑脸，不依赖任何浏览器状态或会话。
- 因无数据读写，无需声明应用负责的数据读写边界。

## 4. 实现入口与运行方式

- 标准新建 React/Vite SPA 结构：`index.html` + `src/main.jsx` 挂载根组件，笑脸 SVG 位于根页面组件内。
- 本地运行：安装依赖后执行 `npm run dev` 启动 Vite 开发服务器，在浏览器访问其根路径即可查看笑脸页面。
- 生产形态：`npm run build` 产出静态 `dist`，可直接静态托管访问；两种方式均满足"页面可直接在浏览器打开查看"的语义。

## 5. 验收承载结论

AC-01 的 runtime-render 验证由上述单页静态渲染直接承载：在浏览器打开根路径即呈现由圆形脸部、眼睛与上扬嘴角构成的完整笑脸，无需任何额外操作。
