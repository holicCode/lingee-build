# 哭脸界面架构基线（WorkItem wi-t1000353）

- 需求基线：`docs/wi-t1000353/requirements.md`（分类时已按 sha256 校验，为产品范围唯一来源）。
- 设计路线：`simple-frontend`（compact 路线）。本应用无任何服务端能力需求，全部功能在浏览器内完成。

## 页面与交互范围

- 单一展示页面：打开即渲染完整哭脸表情图形，元素包括圆形脸部轮廓、位于脸部上部的眼睛、位于脸部下部的下垂弧线嘴角，以及自眼部下方垂落的泪滴，各元素同屏可见。
- 无用户交互、无表单、无路由跳转；页面为纯展示，打开即呈现最终形态。
- 表现细节（页面标题、配色、尺寸、动画）需求未规定，实现阶段采用保守默认值：暖黄色圆形脸、深色描边与瞳孔、浅蓝色泪滴，表情居中布局，默认不做动画。

## 浏览器状态与数据归属

- 无应用数据、无用户生成内容、无持久化需求；页面不使用 localStorage 或其他浏览器存储，无读写边界需要声明。
- 不存在服务端、API、数据库、认证、后台任务、外部集成或数据同步层；刷新或重新打开页面后展示内容不变。

## 实现入口

- 新建 React + Vite SPA（npm）：采用 Vite React 模板标准入口（`index.html` 挂载 `src/main.tsx`），根组件为单页哭脸展示组件，无额外路由与状态管理。
- 哭脸图形以声明式内联 SVG 实现：`<circle>` 绘制圆形脸部轮廓，椭圆/圆绘制眼睛，路径（贝塞尔或圆弧）绘制下垂嘴角，泪滴用路径在眼部下方垂落绘制；通过 SVG `viewBox` 保证图形在任意视口尺寸下等比缩放、清晰不失真。

## 运行方式

- 开发与验证：`npm install` 后 `npm run dev` 启动 Vite 开发服务器，在浏览器打开返回的本地 URL 即可查看哭脸页面，无需登录或任何前置操作。
- 构建产物：`npm run build` 生成纯静态资源；`npm run preview` 可在本地预览构建结果，同样直接打开即可查看。
- 目标浏览器：现代桌面浏览器（Chrome / Edge / Safari / Firefox 最新稳定版）。
