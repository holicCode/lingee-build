# 架构基线：羽毛球主视觉 Web 界面（wi-t1000425）

本基线基于已批准的需求快照 `docs/wi-t1000425/requirements.md`（sha256: f98fe1179f8a7d2000d16ba3717e070ec8b61236aa1789ecb7e0b9c3fad65de8）设计，不扩展或重裁其产品语义。

## 路线结论

应用类型为 `simple-frontend`（紧凑路线）。需求为单页纯视觉展示：无服务端权威数据、无认证、无后台任务、无外部集成、无跨用户/设备共享，AC-03 的本地启动与浏览器访问由前端开发服务器承载。

## 页面与交互范围

- 单页应用（SPA），一个全屏主舞台，页面中心区域呈现羽毛球主视觉：球头（球托+球裙底缘）与放射状羽片两部分结构清晰、轮廓可辨。
- 整页统一视觉风格与主题（背景、光效、文字排版与主视觉同风格语言），具备动效与光影层次：包括主视觉入场动画与持续循环的光影/动效（如呼吸光晕、羽片微动、粒子/光斑背景）。
- 响应式布局：以视口尺寸断点（桌面/移动）自适应缩放主视觉与排版，两种视口下主视觉均保持中心呈现，无错乱、重叠或溢出。
- 交互范围限于视觉层（动画播放与响应式重排）；无业务数据录入、无业务流程状态机、无页面路由跳转。

## 浏览器状态与数据归属

- 本页面无业务数据，不使用 `localStorage` 或任何持久化存储。
- 所有视觉状态（动画进度、当前播放的动效阶段）仅存在于当前浏览器标签页的内存中，由 CSS 动画/JS 渲染层管理；刷新或重开后回到初始视觉状态，符合需求的纯展示定位。

## 实现入口与运行方式

- 新建应用采用 React/Vite SPA（项目目录在本 WorkItem 工作区内初始化）。
- 主视觉（球头与放射状羽片）以 SVG/CSS 结构化绘制为主，保证结构清晰可辨并便于做光影/动效分层；动画优先使用 CSS 关键帧与少量 JS 驱动。
- 运行方式：`npm run dev` 启动 Vite 开发服务器，浏览器访问开发服务器地址（默认 `http://localhost:<port>`，以实际启动输出为准）。

## 动效可重复验证（AC-02）

- 动效均为确定性动画：入场动画为固定时长的单次播放，循环光影动效为固定周期循环，无随机结果、无外部异步事件、无长状态路径。
- 验证方式：循环动效可直接在页面上持续观察；入场动画通过刷新页面重放；两种视口的响应式表现通过调整浏览器视口尺寸或设备模拟直接观察。无需预置状态、测试控制入口或手动推进，验证后无需恢复初态（无持久状态）。

## 边界

- 不引入服务/API、数据库、认证、后台任务、外部集成或同步层；不生成技术契约、bootstrap 计划或 ADR。
- 配色、动效形式、页面文案等信息结构由实现阶段在需求允许范围内自主决策。
