# 实现报告：羽毛球主视觉 Web 界面（wi-t1000425 · implementation）

## 交付行为

新建 React 19 + Vite 7 单页应用，交付一个以羽毛球为主视觉的炫酷 Web 界面：

- **中心主视觉**：结构化 SVG 绘制的羽毛球，位于页面视口中心——软木球头（径向渐变 + 皮革缠线纹理 + 呼吸高光）、白色皮环连接件、13 片以 ±42° 对称放射展开的羽片（羽瓣渐变 + 羽梗线条 + 两道编织线圈），球头与羽片两部分结构清晰可辨。
- **统一视觉风格与光影动效**：深空青蓝主题贯穿背景（径向渐变 + 斜向光束 + 暗角）、霓虹光晕呼吸、粒子上浮、主体入场（升起定位）与持续浮动、羽片按角度错相微摆、地面投影随浮动缩放呼吸、球头高光呼吸；标题为渐变文字，注脚以同色系点缀。
- **响应式布局**：视口三段网格（标题 / 主视觉 / 注脚），主视觉以 `min(66vw, 400px)` 缩放并始终保持居中；≤640px 移动断点下调整字号、字距、主视觉宽度（`min(82vw, 330px)`）并减半粒子数量，无重叠或溢出。
- **可运行性**：`npm run dev` 本地启动，浏览器访问 Vite 输出地址；无业务数据、无持久化状态、无网络请求，刷新即回到初始视觉状态。

## 实现范围与调用链

调用链：`index.html` → `src/main.jsx`（React 挂载）→ `src/App.jsx`（页面布局 + `Shuttlecock` SVG 组件：羽片角度表、编织线圈、球头渐变与高光）→ `src/index.css`（主题变量、关键帧动画、响应式断点）。
